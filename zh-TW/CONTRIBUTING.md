# 貢獻指南

歡迎提出想法、回報問題與貢獻。審查著重兩點：

1. **安全性：**只操作使用者指定的已配對裝置，保留系統保護，減少權限，避免洩漏本機裝置資訊。
2. **效能：**減少閒置工作，以事件取代輪詢，合併密集通知，將會阻塞的藍牙呼叫移出 UI。

重現方式、安全影響分析或修改前後的效能測量都很有幫助。選擇能說明上述兩點的檢查即可，這裡不額外要求程式風格或功能清單。

其他想法不是不行，歡迎討論；但本專案**不提供外掛系統或外掛 API**。仍可提議內建功能，或自行維護分支。

本機可使用 `swift test` 與 `bash scripts/build-app.sh`。貢獻適用專案的 [Apache-2.0 授權](../LICENSE)；私下回報漏洞請見[安全政策](SECURITY.md)。
