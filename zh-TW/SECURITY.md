# 安全政策

安全修正以最新 1.x 版本為主。請勿在公開 issue 貼出裝置地址、配對資訊、Token 或私人紀錄。

優先使用 Repository 的 **Security → Report a vulnerability** 私密管道。若無法私密回報，先請求私人聯絡方式，不公開漏洞細節。請提供影響、重現方式及受影響版本；不承諾固定回覆時限。

App 需要系統藍牙權限，不需要 root 或停用 SIP。官方產物使用 ad-hoc 簽章，尚未公證；請比對 SHA-256，依 README 只針對本 App 設定開啟例外。校驗碼相符代表檔案與發布內容一致，並非獨立的無害保證。
