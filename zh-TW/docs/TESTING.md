# 測試

自動檢查：`swift test`、`bash scripts/build-release.sh`，以及打包執行檔的 `--check-localizations`、`--probe-lid 2`。發布腳本檢查架構、語系資源、plist 及簽章；將 DMG 唯讀掛載後重做檢查，以驗證實際下載產物。

九個核心測試涵蓋闔蓋轉換、暫停與初始狀態、地址識別、設定與語言保存、事件合併、偏好語言偵測、66 個翻譯鍵值與格式參數，以及切換後的既有訊息翻譯。

## 硬體驗收

1. 保持暫停，允許藍牙，依名稱與地址確認 Cleer ARC II。
2. 從 macOS 控制耳機連線／斷線，確認不按重新整理也會更新；選單關閉及讀取途中也要測試。
3. 播放音訊並按手動斷線，比對 API 結果、Mac 連線與音訊、耳機狀態，以及 iPhone／iPad 是否能接手空出的名額。
4. 若 API 失敗、持續連線或重連，保留紀錄並停止相關發布改動，等待設計決策。不得改用私有 API 或關閉控制器。
5. 手動重連後，用使用者原有的 Amphetamine 設定測試實際闔蓋／開蓋；也測試停用 Amphetamine、只有螢幕休眠與重複事件。已闔蓋時啟動不得立即斷線。
6. 檢查每個語言選項、保存、系統回退、長文字及既有紀錄重譯；從固定位置測試登入項目及真正重新登入後啟動。

代理人未操作實際闔蓋、耳機斷線或重新登入。開蓋初始狀態讀取、編譯測試、資源載入與打包結果各自為獨立證據；Intel 交叉編譯不代表已在 Intel 或 macOS 14 實機運行。
