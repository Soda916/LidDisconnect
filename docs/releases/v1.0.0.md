# LidDisconnect 1.0.0

Native macOS menu bar app for disconnecting selected Bluetooth devices when a MacBook lid physically closes. Requires macOS 14+. Universal download includes Apple Silicon and Intel code; Intel runtime has not been tested locally.

- Automatic device refresh on Bluetooth connection/disconnection events, with manual Refresh retained.
- Eight complete local UI languages: English, Traditional/Simplified Chinese, Japanese, Korean, German, French and Spanish. Automatic system detection; saved language menu immediately left of Quit.
- Selected-address-only disconnect, pause/enable, bounded reconnection checks, activity diagnostics and launch-at-login controls.
- Apache-2.0 source and included license/notice.

## Install / opening the app

Quit any older LidDisconnect instance. Download the DMG, drag the app to Applications, eject the image and launch from Applications. The ZIP is an alternative; verify downloads against SHA256SUMS.txt.

The app is **ad-hoc signed, not Developer ID signed or notarized**. If first launch is blocked, attempt opening it, then use **System Settings → Privacy & Security → Open Anyway** for LidDisconnect. Only proceed if you trust the source. [Apple instructions](https://support.apple.com/en-us/102445). Do not disable Gatekeeper or SIP globally.

Grant Bluetooth permission, select headphones by name and address, and run the manual disconnect test while paused before enabling automation.

## Verification limits

Local build/unit tests, architecture/resource/signature checks and packaging are separate from hardware acceptance. Cleer ARC II audio/multipoint slot release, Amphetamine physical-lid behavior, all Bluetooth event paths and actual login relaunch remain unverified. Public API success alone is not proof of headphone slot release. See the repository testing guide.

The published binaries/source tag were built using Swift 6.4 / Xcode 27.1. For source builds on older Swift 6 toolchains, use the latest main branch, which includes optional-pattern and SwiftPM localization-layout compatibility fixes. Published tag and binary downloads remain unchanged.
